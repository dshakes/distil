# Vendored MCP tool lists

Each `*.json` here is the verbatim `tools/list` response of a Model Context Protocol
reference server, captured over stdio on 2026-09-24 (package and version in each
file's `source` / `serverInfo`). They are tool *metadata* only — names, descriptions
and JSON Schemas — used as the fixture catalog for `distil mcp bench` and the proxy's
tests. No server code is vendored.

Source: https://github.com/modelcontextprotocol/servers (and its archived
`servers-archived` repo for `server-github`). That project is transitioning from the

redistribution with attribution, which this notice provides. Copyright remains with
